# GitGetAppVault — Privacy Policy

**Effective Date:** March 21, 2026
**Last Updated:** March 21, 2026
**Version:** 1.0.0

Published by **Sudarshan Tech Labs** | sudarshantechlabs@gmail.com

---

GitGetAppVault is a GitHub repository browser for Android. All cached data is stored exclusively on your device. SudarshanTechLabs does not collect any personal data.

---

## Data Collection

### Data Stored Locally on Your Device

| Data | Purpose | Storage |
|---|---|---|
| Cached repository data | Reduce GitHub API calls | Local (Room DB) |
| Search history | Convenience | Local (DataStore) |
| App preferences | Theme, settings | Local (DataStore) |
| GitHub auth token | API authentication | Local (Android Keystore AES-256) |

### No Data Sent to SudarshanTechLabs
We do not collect analytics, crash reports, location data, or any personal information.

---

## GitHub Authentication

Sign-in uses GitHub's Device Flow — you approve access on GitHub's website. The resulting token is stored locally with Android Keystore encryption and only ever sent to GitHub's API.

---

## Permissions

| Permission | Why |
|---|---|
| INTERNET | Fetch repository data from GitHub API |
| ACCESS_NETWORK_STATE | Check connectivity before requests |
