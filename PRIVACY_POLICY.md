# GitGetAppVault Privacy Policy

**Effective Date:** March 21, 2026
_Last updated: March 21, 2026_
**Version:** 1.0.0

GitGetAppVault ("we," "our," or "us") is a GitHub repository browser for Android developed by SudarshanTechLabs. This Privacy Policy explains how the app handles your data.

## Information We Collect

### No Personal Data Collected by SudarshanTechLabs
We do not collect, store, or transmit personal information, location data, device identifiers, crash reports, or analytics.

### Data Stored Locally
- Cached repository data (to reduce GitHub API calls).
- Search history for convenience.
- App preferences (theme, settings).
- GitHub authentication token (encrypted with AES-256-GCM via Android Keystore, hardware-backed where supported).

### GitHub Authentication (Optional)
- If you sign in with GitHub, the app uses GitHub's Device Flow — you authenticate on GitHub's website directly.
- The resulting access token is stored locally on your device using Android Keystore encryption.
- The token is only ever sent to GitHub's API — never to any SudarshanTechLabs server.

## How We Use Your Information

- Browse GitHub repositories via the GitHub API.
- Cache repository data locally to reduce API calls.
- Remember your search history and preferences.

We do not sell, rent, or share your data.

## Storage and Retention

- All data is stored exclusively on your device.
- All local data is cleared when you uninstall the app.
- No SudarshanTechLabs server stores your data.

## Data Security

- GitHub auth token is encrypted using AES-256-GCM via Android Keystore.
- All communication with GitHub's API is over HTTPS/TLS.

## Third-Party Services

- **GitHub API**: Repository data is fetched from the GitHub API. See [GitHub's Privacy Policy](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

## Permissions Used

- **INTERNET**: Required to fetch repository data from the GitHub API.
- **ACCESS_NETWORK_STATE**: Used to detect network availability before making requests.

No other permissions are requested. The app does not access your camera, microphone, contacts, location, or files.

## Your Rights and Controls

- Sign out at any time to remove the stored GitHub token.
- Clear cached data in Android Settings → Apps → GitGetAppVault → Clear Cache.
- Uninstall the app to remove all local data.

## Children's Privacy

GitGetAppVault is not intended for children under 13. We do not knowingly collect data from children under 13.

## Changes to This Policy

We may update this policy to reflect new features or legal requirements. Continued use after changes constitutes acceptance.
