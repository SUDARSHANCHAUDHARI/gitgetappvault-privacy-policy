GitGetAppVault Privacy Policy

Effective Date: May 17, 2026 _Last updated: November 9, 2026_ Version: 1.2.0

GitGetAppVault ("we," "our," or "us") is a Kotlin Multiplatform app. GitGetAppVault is a Kotlin Multiplatform GitHub repository browser that can search GitHub and optionally authenticate through GitHub device flow. This Privacy Policy explains what information the app collects, how it is used, and the choices you have. By installing or using GitGetAppVault you agree to the practices described below.

Information We Collect

Location Data

  • GitGetAppVault does not collect location data.

Account Information

  • You may optionally authenticate with GitHub. Authentication tokens are stored locally on your device using platform secure storage where available.
  • No Sudarshan Tech Labs account is required.

Device Information

  • Repository search queries, cached repository metadata, app preferences, and optional GitHub authentication state may be stored locally.

How We Use Your Information

Location Sharing

  • GitGetAppVault does not use your location.

Account Management

  • Authenticate to GitHub when you choose to access authenticated GitHub API features.
  • Cache repository data so the app feels faster and remains useful offline.

Service Improvement

  • Improve browsing, search, and repository viewing workflows.
  • We do not operate a server that stores your GitHub token or repository activity.

Storage and Retention

Data Storage

  • GitHub tokens are stored locally using secure platform storage where supported.
  • Repository metadata and preferences are cached locally.
  • GitHub API requests are sent directly to GitHub.

Data Retention

  • Local cache and tokens remain until you sign out, clear app data, or uninstall the app.
  • GitHub retains API/account data according to GitHub policies.

Data Security

  • Your GitHub token is held in the platform's secure storage where one is available, inside the app's private storage.
  • In transit, requests to the GitHub API go over HTTPS.
  • No Sudarshan Tech Labs server exists, so there is no third place holding your data. The app uses no Firebase — only a google-services.json.example sample file is in the repository, and no Firebase dependency is declared in any build file.
  • Local data remains on your device or browser unless a feature you use requires a named third-party service.
  • Network communication uses HTTPS/TLS where applicable.
  • You should protect your device, browser profile, and Google/GitHub accounts with strong authentication.

Data Sharing

Sharing With Other People

  • GitGetAppVault has no sharing, pairing or collaboration features. It is a single-user tool for browsing your own GitHub account.

Third Parties

  • GitHub, and nothing else. GitHub receives API requests, search queries and authentication requests when you use GitHub features, at api.github.com, and serves profile images from avatars.githubusercontent.com. Those are the only hosts the app contacts.
  • Requests use your own GitHub token, so GitHub processes them under your own account.
  • The app contains no analytics service, no crash reporting, no advertising SDK and no Firebase. It does keep an on-device usage record (UsageAnalyticsManager) to drive in-app suggestions; that code makes no network calls and the record never leaves your device.

We do not share your data with:

  • Data brokers
  • Unrelated advertising networks, unless advertising is explicitly listed above for this app
  • Third parties unrelated to the app features described in this policy

Permissions Used

Required Permissions

  • INTERNET: Required to communicate with the GitHub API.
  • ACCESS_NETWORK_STATE: Used to check connectivity.

Optional Permissions

  • GitHub authentication is optional; unauthenticated browsing can be used where GitHub rate limits allow.

Your Rights and Controls

Location Sharing Control

  • No location sharing exists in GitGetAppVault.

Account Management

  • You can sign out to remove locally stored GitHub authentication state.
  • GitHub account data is managed in your GitHub account settings.

Data Access

  • You can clear local cache and app data through app or system settings.

  • Browser permissions and storage can be managed in your browser site settings for web apps.
  • Revoking required permissions may prevent related features from functioning.

Children's Privacy

  • Our app is not intended for children under 13.
  • We do not knowingly collect data from children under 13.
  • If you are a parent or guardian and believe your child has provided personal information, please contact us to request deletion.
  • Parents and guardians should supervise children's use of apps that store personal content.

Security

  • Local data is protected by Android, browser, or operating-system app sandboxing.
  • Network communication uses HTTPS/TLS where applicable.
  • Third-party services named in this policy provide their own security controls and privacy policies.
  • You are responsible for protecting your device, browser profile, and account credentials.
  • We do not sell your personal data.

Data Deletion

How to Delete Your Account:

This app does not require an account. You can delete local app data using the options below:

Option 1: In-App Deletion

1. Open GitGetAppVault 2. Delete individual entries, reminders, history, or settings where the app provides controls 3. Or use Android/browser settings to clear app/site data 4. Uninstalling the app also removes local app-private data

Option 2: Email Deletion Request

Send an email to: support@sudarshantechlabs.com or sunny.sudarshan@gmail.com

  • Subject: "Data Deletion Request - GitGetAppVault"
  • Include: The email/account identifier used in the app, if any
  • We will process deletion requests as quickly as possible, typically within 48 hours for acknowledgement

Option 3: Web Deletion

1. Visit the privacy policy website for contact and support information 2. For browser apps, clear browser storage for the site 3. For Android apps, clear storage from Android Settings if you want a full local reset

What Gets Deleted:

  • Local app data stored by the app
  • Local preferences and reminder/history records
  • Cached data controlled by the app or browser
  • Exported/shared files only if you delete them from where you saved them

Data Retention After Deletion:

  • Immediate: clearing app/site data removes local app-private data from your device/browser
  • Uninstall: removes app-private local data from Android apps
  • Exports/shared files: remain wherever you saved or sent them until you delete them

To request deletion of your data:

1. Open GitGetAppVault, if installed 2. Delete local content or clear app/site data where applicable 3. Contact support via email: sunny.sudarshan@gmail.com 4. Request account/data deletion and include enough detail for us to identify the app and any account, if one exists 5. We will confirm what data can be deleted and complete the request according to the retention terms above

About GitGetAppVault

GitGetAppVault is built with privacy in mind. The app is built with:

  • Kotlin Multiplatform
  • Compose Multiplatform
  • GitHub API integration
  • Secure local token storage where available

The app collects only the data needed for the features described in this policy, and local-first features keep data on your device whenever possible.
