Privacy Policy — GitGetAppVault

Last updated: April 26, 2026

Overview

GitGetAppVault is a GitHub repository browser developed by SudarshanTechLabs. This policy explains how the app handles your data. The short version: we collect as little as possible and keep everything on your device.

What We Don't Collect

We do not collect, store, or transmit:

  • Personal information or real name
  • Location data
  • Device identifiers or advertising IDs
  • Crash reports or analytics
  • Browsing history outside the app
  • Any data to our own servers — we have none

Permissions

The app uses the following Android permissions:

  • INTERNET — required to fetch repository data from the GitHub API.
  • ACCESS_NETWORK_STATE — used to detect whether a network connection is available before making requests.

No other permissions are requested. The app does not access your camera, microphone, contacts, location, or files.

GitHub Authentication

If you choose to sign in with GitHub, the app uses GitHub's Device Flow — you visit GitHub's website directly and approve access there. The resulting access token is stored locally on your device using Android Keystore encryption (AES-256-GCM, hardware-backed where supported). The token is never sent to anyone other than GitHub's API.

Local Storage

The app stores the following data locally on your device only:

  • Cached repository data to reduce API calls
  • Search history for convenience
  • Your preferences (theme, settings)
  • GitHub auth token (encrypted, as described above)

All local data is cleared when you uninstall the app.

Third-Party Services

The app communicates exclusively with the GitHub API (api.github.com) to load repository and user data. Your use of GitHub is subject to GitHub's Privacy Policy.

No other third-party SDKs, analytics libraries, or ad networks are included in the app.

Children's Privacy

This app is not directed at children under 13. We do not knowingly collect any information from children.

Changes to This Policy

If this policy changes, the updated version will be posted at this URL with a new "Last updated" date.
